Install the development extension

For advanced users

Install Rust with rustup, make sure silex is available in your PATH, then clone the extension repository. 

git clone https://github.com/Matanek/Silex-Extension-Zed.git
cd Silex-Extension-Zed
rustup target add wasm32-wasip2
  1. Open the Zed command palette.
  2. Run zed: install dev extension.
  3. Select the cloned Silex-Extension-Zed folder.
  4. Open a .sx file and start coding.

Updating the clone later? Pull the changes, then run zed: rebuild dev extension. Node.js and npm are only needed if you plan to regenerate or test the Tree-sitter grammar.
